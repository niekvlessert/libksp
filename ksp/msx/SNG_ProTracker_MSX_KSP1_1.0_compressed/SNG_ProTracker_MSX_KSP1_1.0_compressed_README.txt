SNG + Pro Tracker compressed MSX-profile KSP 1.0 builds
========================================================

Files
-----
SNG_All_MSX_KSP1_1.0_compressed.ksp
  98 tracks, 493 logical pages.
  711,685 bytes.
  Runtime page: 4000h-7FFFh.
  Engine: 4000h-40CEh.
  Data window: 6000h-7FFFh.
  Dynamic KSP gateway: 17E0h.
  Reuses the original forward-ZX0 8 KiB bank streams in PBK1 slabs.

ProTracker_All_MSX_KSP1_1.0_compressed.ksp
  158 tracks, 158 logical pages.
  137,749 bytes.
  Runtime page: 4000h-7FFFh.
  Relocated engine: 4000h-4FFFh (originally CA00h-D9FFh).
  Song window: 5000h-7FFFh (originally page 0).
  Reuses 157 original forward-ZX0 song streams as RMP1 DATA resources.
  Track 152 uses one 6,231-byte uncompressed compatibility resource because
  the old song follows a malformed/out-of-range pointer chain into KSS filler.

Validation
----------
- KSP1 magic at file offset zero.
- Header/index/resource/page CRCs valid.
- Every original ZX0 stream decodes to its original logical bytes.
- Every KSP runtime page materializes byte-identically to the expected page.
- SNG: 98/98 tracks match the original chip-write sequence for 600 PLAY ticks.
- Pro Tracker: 158/158 tracks match for 600 PLAY ticks.
- Pro tracks 150-157, including special track 152, also match for 3,600 ticks.

MSX player requirement
----------------------
These files target the finalized standalone KSP 1.0 MSX profile, including
PBM1/PBK1 shared-block pages, RMP1 resource-map pages, and gateway 17E0h.
They are not compatible with the older repository KSPPLAY.COM that still reads
KSSX/KCPX/KCPZ and the older compact trailer-style KSP1 resource format.
A KSPPLAY.COM implementing the finalized standalone KSP1 parser/materializer is
still required for real MSX playback.

No physical MSX or audible openMSX test was performed in this build environment.
