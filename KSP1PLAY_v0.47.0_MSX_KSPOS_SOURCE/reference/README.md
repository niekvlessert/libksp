# Canonical reference

The hashes here come from `KSP1PLAY_v0.47.1_BASE(2).DSK`. The disk identifies the embedded player as v0.47.0.

`KSP1PLAY.COM` is used **only as a historical byte-reference name**. The clean source build calls the same 30,464-byte payload `KSPPLAYER.BIN` and embeds it directly in `KSPBOOT.BIN`; the generated bootable disk does not need a COM file.
