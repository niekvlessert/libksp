# TinyKSP 1.9.8

- Right Arrow still selects the next playable track inside the current KSP.
- Right Arrow on the final playable track immediately opens the next KSP in a wildcard or multi-file playlist.
- Track navigation no longer wraps from the final track back to track 1.
- Automatic track-end and next-file progression from 1.9.7 remains unchanged.
