# Third-party components

## z80dasm 1.1.6

The package contains an unmodified original source archive:

`third_party/z80dasm_1.1.6.orig.tar.gz`

and a Linux x86-64 binary built from that source. z80dasm is distributed under
the GNU General Public License version 2. A copy is included as
`licenses/z80dasm-GPL-2.0.txt`.

## zx0_codec.py

Copied from the supplied HOOT_KSS2KSP_NATIVE v0.10.0 converter source and used
only to decode KSP ZX0 payloads for analysis.
